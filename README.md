# effective-sets

An open exercise base with **fractional per-muscle weights**, a tiny volume calculator, and a
shareable end-of-workout card. Everything runs in the browser. No account, no server.

- Volume is counted in **effective sets**: sets taken to 0–2 reps in reserve. Reps and tonnage are
  not tracked on purpose.
- One set gives 1.0 to the muscle that limits the exercise and fractions to the helpers
  (a pull-up: lats 1.0, mid back 0.6, biceps 0.5 …).
- The muscles on the card come **from the table, not from sensors**. The card says so.

The base is meant to be a foundation for anyone building their own tracker: take
`data/bundle.json` (or the per-exercise files) and `src/compute.js`, and you have the maths.

## Layout

```
data/
  muscles.json          25 muscle groups (frozen taxonomy), names en/ru, body-map views
  exercises/<id>.json   one exercise per file: names, aliases, equipment, weights, source
  bundle.json           generated by `npm run build` — what the browser loads
src/
  compute.js            sets × weights → volume per muscle (no dependencies)
  sessions.js           logged sessions: add/undo sets, move a day, CSV export
  body.js               body map shapes, keyed by muscle id
  i18n.js               t() helper over locales/*.json
app/                    index.html  «Ready to work out?» + one button
                        log.html    log sets during or after the workout (date editable)
                        card.html   the end-of-workout card
                        store.js    localStorage (sessions stay on the device)
locales/                UI strings, ru + en
examples/ivan/          a real training log used as test fixture
tools/                  import-csv (one-off), build-bundle, validate
test/                   node --test
docs/FORMAT.md          the rules behind the numbers
```

## Use

```bash
npm run build     # regenerate data/bundle.json after editing data/
npm run lint      # validate the base
npm test          # includes: every session in examples/ivan reproduces its volume_log.csv
npm run serve     # then open http://localhost:4173/app/
```
